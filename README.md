# Zero-Shot Text Classification using Hugging Face

## 📌 Overview

This project demonstrates Zero-Shot Text Classification using Hugging Face Transformers. Unlike traditional machine learning models, Zero-Shot Classification predicts labels that were never seen during training.

The model can classify text into any user-defined categories without requiring additional training.

---

## 🚀 Features

- Zero-shot text classification
- No model training required
- Uses pre-trained Hugging Face models
- Supports custom labels
- Simple implementation using Python

---

## 🛠️ Technologies Used

- Python
- Hugging Face Transformers
- PyTorch
- Google Colab / Jupyter Notebook

## Example

Input

```
Text:
"I want to buy a new laptop for programming."

Candidate Labels:
Technology
Sports
Politics
Education
Shopping
```

Output

```
Shopping
Technology
```

(with confidence scores)
